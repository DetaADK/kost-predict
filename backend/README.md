# Backend Django REST Framework

Folder ini disiapkan untuk tahap backend. Belum ada kode Django karena kita
akan menyelesaikan dan mengevaluasi model terlebih dahulu.

Nantinya API menerima fitur kos dalam JSON, memanggil pipeline `.joblib`,
lalu mengembalikan prediksi harga. Database tidak wajib untuk MVP prediksi.
